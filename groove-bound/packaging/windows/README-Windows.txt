GROOVE BOUND {{VERSION}} - WINDOWS X64

1. Extract the complete Groove Bound folder from the ZIP.
2. Keep Groove Bound.exe and every DLL together in that folder.
3. Double-click Groove Bound.exe. LÖVE does not need to be installed.

This development preview is unsigned. Windows Defender SmartScreen may show a
warning on first launch. Use "More info" and "Run anyway" only if you obtained
this ZIP from the official raoniai/groovebound-2026 GitHub Release and its
SHA-256 matches the published release manifest.

Saves are stored under %APPDATA%\groove-bound. On first launch, Groove Bound
can safely import validated saves previously created by the platform-neutral
.love build under %APPDATA%\LOVE\groove-bound. The original files are retained.

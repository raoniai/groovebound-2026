## Additional verified public GitHub experiments

### AE Script Panels

- **Repository:** [`raoniai/AE-Script-Panels`](https://github.com/raoniai/AE-Script-Panels)
- **Safe description:** A public collection of After Effects ScriptUI panel experiments and production utilities.
- **First-party evidence:** The current public repository tree contains named tools including `3D Carousel`, `Auto Comp Handler`, `Batch Renamer`, `Clean Expressions`, `Marker Text Animator`, `Relink Expressions`, `Speech Bubble`, `Time Remap Manager`, `Trim Paths Animator`, and `True Duplicator`.
- **Builder-page value:** Stronger than repeating Master Script Pack alone because it shows a broader pattern of small practical tools connecting motion craft, automation, and workflow design.
- **Status boundary:** No root README or visual previews are present. Describe the named tool collection, but do not claim readiness, adoption, or compatibility.

### GrooveBound — early public build

- **Repository:** [`raoniai/004_GrooveBound`](https://github.com/raoniai/004_GrooveBound)
- **Safe description:** An early LÖVE2D/Lua rhythm-based top-down shooter experiment with waves, upgrades, drones, area attacks, responsive UI, and real-time settings.
- **Evident status:** The first-party [README](https://github.com/raoniai/004_GrooveBound/blob/main/README.md) calls it a work in progress and learning exercise; it also states that the on-beat bonus was not working in that build.
- **Builder-page value:** Useful as a small “prototype to system” timeline point, showing iteration toward the current game. It should not receive a download CTA.

### Groove Bound — current Stage 4 repository

- **Repository:** [`raoniai/groovebound-2026`](https://github.com/raoniai/groovebound-2026)
- **Safe description:** The current music-powered survival roguelike repository, combining manual movement, automatic attacks, XP gems, build choices, rank-10 fusions, three stages, and music-themed enemies.
- **Evident status:** The first-party [README](https://github.com/raoniai/groovebound-2026/blob/main/README.md) identifies the build as a playable Stage 1–4 vertical slice and describes BeatClock/groove work as the next planned layer.
- **Builder-page value:** The primary public game case study and strongest current repository link. Keep it distinct from the legacy `004_GrooveBound` process milestone.

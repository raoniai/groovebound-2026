## Strong Builder-page candidates

### Bark & Chase / Dogs vs Cats

- **Exact repository:** [`raoniai/002_DogVsCats`](https://github.com/raoniai/002_DogVsCats)
- **Public project name in README:** **Bark & Chase!**
- **Accurate short description:** A mouse-controlled yard game where the player patrols as a dog, listens for cats, clicks to bark, and tries to chase every cat away as quickly as possible.
- **Evident status:** The README labels it **v1.0.2**, calls it a research and educational test project, and links to a playable/downloadable Itch.io release.
- **Source:** [project README](https://github.com/raoniai/002_DogVsCats/blob/main/README.md)
- **Suggested Builder-page framing:** “Bark & Chase was a compact playable experiment in character, sound cues, timing, and learning game development by shipping.”

### RaoLatro

- **Exact repository:** [`raoniai/001_Poker`](https://github.com/raoniai/001_Poker)
- **Public project name in README:** **RaoLatro**
- **Accurate short description:** A Balatro-inspired poker prototype built in Lua and LÖVE2D as Raoni’s first playable game-development experiment, using AI as a learning, coding, debugging, and ideation collaborator.
- **Evident status:** The README explicitly describes it as an early, rough learning prototype rather than a finished product. Documented working features include playable poker hands, discard and draw, scoring, game-over/restart, debug mode, and simple sound effects.
- **Source:** [project README](https://github.com/raoniai/001_Poker/blob/main/README.md)
- **Suggested Builder-page framing:** “RaoLatro marks the start of my hands-on game-making journey: using AI as co-pilot while learning Lua, LÖVE2D, game states, animation, input, debugging, and Git.”

### GrooveBound: early public build

- **Exact repository:** [`raoniai/004_GrooveBound`](https://github.com/raoniai/004_GrooveBound)
- **Accurate short description:** An early rhythm-based top-down shooter built with LÖVE2D and Lua, combining dodging and shooting with beat-synchronised scoring ideas, waves, upgrades, drones, area attacks, UI, and real-time settings.
- **Evident status:** The README calls it a work in progress and learning exercise; it also notes that the on-beat bonus was not working in that build.
- **Source:** [project README](https://github.com/raoniai/004_GrooveBound/blob/main/README.md)
- **Suggested Builder-page framing:** Use as a process milestone, not as the current download: “The early GrooveBound build was where rhythm, survival combat, modular Lua systems, and rapid iteration first converged.”

### Groove Bound: current public development repository

- **Exact repository:** [`raoniai/groovebound-2026`](https://github.com/raoniai/groovebound-2026)
- **Accurate short description:** A music-powered survival roguelike built with LÖVE. The run combines manual movement, automatic attacks, XP-gem collection, build choices, rank-10 weapon fusions, three stages, and music-themed enemies and bosses.
- **Evident status:** The README identifies it as the **Stage 4 development preview** and says the Stage 1–4 vertical slice is playable. The available download is a platform-neutral `.love` package requiring LÖVE 11.5; BeatClock and groove systems are described as the next planned layer.
- **Source:** [current repository README](https://github.com/raoniai/groovebound-2026/blob/main/README.md)
- **Suggested Builder-page framing:** This is the current, primary game case study and should receive the strongest repository CTA.

# Site contract

## Canonical inputs

- Runtime and content: `groove-bound/src/`
- Canon: `groove-bound/docs/FIRST_DRAFT_CANON.md`
- Runtime art: `groove-bound/assets/generated/` and `campaign/`
- Public repository art: `docs/assets/`
- Provenance: runtime asset registers
- Delivery state: live Git evidence and `LATEST_VERSION_HANDOVER.md`

## Site checks

- `node --check script.js`
- No broken local asset references.
- Home, Lore, and Builder load.
- Inspectors match current stable IDs and labels.
- Status data reflects committed history and current dirty count without claiming unrun checks.
- Desktop and mobile have no unintended horizontal overflow.
- Motion has a reduced-motion route.
- Screenshot cards preserve source aspect ratios.

Local preview success does not prove commit, deployment, or public availability.
